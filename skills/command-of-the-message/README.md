# Command of the Message skills

These skills help teams put **Command of the Message®**, the value-based sales messaging methodology from [Force Management](https://www.forcemanagement.com/), into practice. There is one skill for each step of a rollout, plus `cotm-overview`, which explains the methodology, routes requests to the right skill and runs a readiness check.

Every skill is named `cotm-<step>`, and its folder name matches the `name` in its frontmatter.

| Step | Question it answers | Skill |
|---|---|---|
| 1. Foundations | What is Command of the Message, and where do we start? | [`cotm-overview`](cotm-overview/) |
| 2. Executive alignment | Are leaders aligned on the message and committed to the change? | [`cotm-executive-alignment`](cotm-executive-alignment/) |
| 3. Value Framework | What problems do we solve, how do we solve them differently, and where have we done it before? | [`cotm-value-framework`](cotm-value-framework/) |
| 4. Field tools | Can reps use the message in a real conversation? | [`cotm-field-tools`](cotm-field-tools/) |
| 5. Training and certification | Can every customer-facing person deliver the message on demand? | [`cotm-training-certification`](cotm-training-certification/) |
| 6. Sales process integration | Does the message show up in how we qualify, run and forecast deals? | [`cotm-sales-process-integration`](cotm-sales-process-integration/) |
| 7. Coaching and reinforcement | Do managers coach to the message so it sticks? | [`cotm-coaching-reinforcement`](cotm-coaching-reinforcement/) |
| 8. Impact measurement | Is the message changing behavior and revenue results? | [`cotm-impact-measurement`](cotm-impact-measurement/) |

## Related skills in this catalog

- `pragmatic-positioning`, `pragmatic-buyer-personas`, `pragmatic-market-problems` and `pragmatic-competitive-landscape` supply the evidence a Value Framework rests on.
- `pragmatic-organizational-alignment` and `pragmatic-assets` cover the wider go-to-market alignment and sales tools that the message feeds.
- `pragmatic-win-loss-analysis` feeds proof points and differentiators back into the Value Framework.

## About these skills

Command of the Message® and MEDDPICC are associated with Force Management, which delivers the methodology through its own workshops, certified trainers and proprietary materials. These skills are an independent, unofficial guide written from publicly available descriptions of the methodology. They are not affiliated with or endorsed by Force Management, and they do not reproduce its proprietary content. Teams running a formal engagement should treat Force Management's materials as the authority where the two differ.
