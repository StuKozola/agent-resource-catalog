## Quarterly framework refresh checklist

- [ ] Review win/loss findings since last refresh

- [ ] Collect new proof points from customer success and recent wins
- [ ] Check competitive changes and new alternatives
- [ ] Check product launches, pricing or packaging changes
- [ ] Propose Value Framework changes; get owner approval; update change log
- [ ] Update field tools (questions, mantra, talk tracks, objections)
- [ ] Update CRM picklists if differentiators or capabilities changed
- [ ] Run refresher session; re-certify if changes are significant
- [ ] Notify marketing, customer success and partners of changes
