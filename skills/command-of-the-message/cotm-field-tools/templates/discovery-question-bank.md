## Decision context

- Who else is affected by this problem?
- How have decisions like this been made before?
- What has been tried already, and what happened?
- What would need to be true for this to be a priority this quarter?

## Follow-up prompts

- "Tell me more about that."
- "What's the impact of that on [team / goal]?"
- "How are you measuring that today?"
- "What happens if this doesn't change in the next 12 months?"
