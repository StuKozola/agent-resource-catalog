## 1. Five Screening Tests — Detailed Scoring

The five screening tests are the core analytical tool for Cornered Resource. A suspected resource must pass all five tests to qualify as a true Cornered Resource Power. Failure on any single test is disqualifying.

### Test 1: Idiosyncratic

**Question**: Can you identify a specific, named asset, person, team, patent, property, or relationship that explains the differential returns?

**Scoring**:

| Score | Criteria |
|-------|----------|
| Pass (Strong) | A specific, named resource can be identified and clearly linked to differential returns. The resource is unique — no one else has it or anything like it. |
| Pass (Moderate) | A resource can be identified, but its uniqueness requires some argument. Similar resources exist elsewhere but are materially inferior. |
| Fail | The advantage comes from a general capability (e.g., "great engineering culture") rather than a specific, identifiable asset. Or, the firm repeatedly acquires similar resources, suggesting the true source of Power is the *acquisition capability*, not any single resource. |

**Diagnostic questions**:
- Can you name the specific resource?
- If this resource were gone tomorrow, could you point to it as the cause of declining returns?
- Does the firm repeatedly acquire similar advantages? If so, what enables that pattern?

### Test 2: Non-Arbitraged

**Question**: Did the company acquire or retain this resource at terms that leave meaningful differential returns after accounting for the cost?

**Scoring**:

| Score | Criteria |
|-------|----------|
| Pass (Strong) | The resource was acquired at terms well below its value — e.g., developed internally and then patented, or retained key talent at below-market compensation due to loyalty/mission. |
| Pass (Moderate) | The resource was acquired at reasonable terms, with meaningful (but not overwhelming) differential returns remaining after accounting for cost. |
| Fail | The cost of acquiring or retaining the resource captures most or all of the incremental value. Example: hiring a star executive at full market rate, or licensing a patent at rates that eliminate the margin advantage. |

**Diagnostic questions**:
- What did the resource cost to acquire or develop?
- What is the incremental value (revenue uplift, cost reduction, pricing power) it creates?
- Is the difference between value created and cost paid large enough to drive persistent differential margins?
- In talent cases: are key people compensated at, above, or below the market rate for their contribution?

### Test 3: Transferable

**Question**: If this resource were moved to a different company, would it still create comparable value?

**Scoring**:

| Score | Criteria |
|-------|----------|
| Pass (Strong) | The resource has been demonstrated to create value in a different context (e.g., Pixar Brain Trust revitalizing Disney Animation). Or, the resource is inherently context-independent (e.g., a drug patent, a mineral deposit). |
| Pass (Moderate) | The resource would likely create value elsewhere, though the magnitude might differ based on context. |
| Fail | The resource only works because of other unique aspects of the company (culture, complementary technology, market position). Removing those complements would eliminate the resource's value. |

**Diagnostic questions**:
- If a competitor acquired this resource tomorrow, would they benefit comparably?
- Are there complementary factors that make this resource work here but wouldn't exist elsewhere?
- Has the resource (or something similar) been tested in a different context?

### Test 4: Ongoing

**Question**: Is this resource currently driving differential returns, or has its contribution become embedded in the business?

**Scoring**:

| Score | Criteria |
|-------|----------|
| Pass (Strong) | Removing the resource today would clearly and materially diminish differential returns going forward. The business depends on the resource's ongoing presence. |
| Pass (Moderate) | The resource still contributes meaningfully, but some of its historical contribution is now embedded in the company. |
| Fail | The resource was essential historically but its contributions are now fully embedded. The company would continue to generate similar returns without it. |

**Diagnostic questions**:
- If this resource disappeared tomorrow, what would happen to the business over the next 1-3 years?
- Has the resource's contribution diminished over time as the business matured?
- Are there founders or early hires who were essential to building the company but whose continued presence is no longer critical?

### Test 5: Sufficient

**Question**: Is this resource, on its own (assuming operational excellence), sufficient to explain continued differential returns?

**Scoring**:

| Score | Criteria |
|-------|----------|
| Pass (Strong) | The resource alone is clearly sufficient to explain the company's differentiated performance. Remove it, and the differentiation disappears. |
| Pass (Moderate) | The resource is a major contributor but works in concert with other factors. It is necessary but perhaps not fully sufficient in isolation. |
| Fail | The resource explains only a small portion of differential returns. Other factors (market position, scale, brand, process) are more important. |

**Diagnostic questions**:
- If this resource were the *only* unusual thing about the company, would it still outperform competitors?
- What percentage of the differential returns does this resource explain?
- Are there cases where someone with a similar resource failed? If so, what was different?

### Five Tests Summary Matrix

| Test | Key Question | Pass Signal | Fail Signal |
|------|-------------|-------------|-------------|
| Idiosyncratic | Can you name it? | Specific, unique asset | General capability |
| Non-Arbitraged | Acquired cheaply? | Cost << Value | Cost ≈ Value |
| Transferable | Works elsewhere? | Context-independent | Needs complements |
| Ongoing | Still driving returns? | Business depends on it now | Contribution embedded |
| Sufficient | Explains the moat? | Primary driver | Minor contributor |

**Interpretation**: A genuine Cornered Resource should score Pass (Strong) or Pass (Moderate) on all five tests. Failure on any single test is disqualifying. Moderate passes on multiple tests should trigger deeper investigation — the resource may be real but less powerful than initially assumed.

## 2. Fiat Barrier Assessment

Once you've confirmed the resource passes all five screening tests, assess the barrier — the fiat — that protects it.

### Barrier Type Classification

| Barrier Type | Mechanism | Typical Duration | Fragility |
|-------------|-----------|-----------------|-----------|
| **Patent Law** | Legal exclusivity granted by government | 20 years from filing (utility patents); varies by jurisdiction | Medium — known expiration, patent cliffs, and challenge risks |
| **Property Rights** | Ownership of physical assets | Indefinite (as long as ownership is maintained) | Low — property rights are generally durable and well-protected |
| **Regulatory Grant** | Government-issued license, concession, or quota | Varies — some indefinite, some subject to renewal | Medium — regulatory environments can change |
| **Contractual Exclusivity** | Long-term exclusive agreements | Duration of contract | Medium-High — contracts end, counterparties may renegotiate |
| **Personal Choice** | Key individuals staying by loyalty/mission | Indefinite but uncertain | High — people retire, get recruited, change priorities |
| **Trade Secret** | Proprietary knowledge kept confidential | Indefinite (as long as secrecy is maintained) | Variable — can be lost through departure, espionage, or independent discovery |

### Barrier Durability Scoring

Rate each dimension on a 1-5 scale:

| Dimension | Score (1-5) | Assessment Criteria |
|-----------|-------------|-------------------|
| **Time Horizon** | | 5 = 15+ years remaining; 3 = 5-10 years; 1 = <2 years or uncertain |
| **Legal Strength** | | 5 = Well-established, tested legal protection; 1 = Untested or legally ambiguous |
| **Circumvention Risk** | | 5 = No viable workaround exists; 1 = Multiple alternatives available |
| **Renewal Probability** | | 5 = Automatic/highly likely; 1 = Uncertain or contested |
| **External Threat** | | 5 = No regulatory/political risk; 1 = Active regulatory review or political pressure |
| **Overall Barrier Score** | | Average of above |

### Barrier Durability Interpretation

| Average Score | Interpretation |
|--------------|---------------|
| 4.0–5.0 | **Fortress** — The barrier is extremely durable. The Cornered Resource is well-protected for the foreseeable future. |
| 3.0–3.9 | **Strong** — The barrier is solid with manageable risks. Monitor specific vulnerability points. |
| 2.0–2.9 | **Moderate** — The barrier exists but has meaningful vulnerabilities. Active management and contingency planning needed. |
| 1.0–1.9 | **Fragile** — The barrier is weak or expiring soon. The Cornered Resource may not constitute durable Power. |

## 3. Benefit Estimation Framework

Quantifying the benefit from a Cornered Resource is highly situation-dependent. Use the framework below to structure the estimation.

### Benefit Categories

**Pricing Power**: The resource enables charging higher prices than competitors for comparable or superior products.
- Estimate: What price premium does the resource enable? What would pricing look like without the resource?
- Example: A patented drug formulation enables monopoly pricing at 5-10x the generic alternative.

**Cost Advantage**: The resource reduces costs below what competitors can achieve.
- Estimate: What is the cost difference per unit or as a percentage of revenue?
- Example: A cement producer's owned limestone source reduces input costs by 20% versus competitors who must purchase and transport limestone.

**Superior Product**: The resource enables a product quality or capability that competitors cannot match.
- Estimate: What revenue is driven by the differentiated capability? What market share does it capture that wouldn't exist without the resource?
- Example: Pixar's Brain Trust produced consistently superior animated films, capturing box office returns well above industry norms.

### Benefit Magnitude Scoring

| Score | Benefit Level | Typical Characteristics |
|-------|-------------|----------------------|
| 5 | **Transformative** | The resource creates 50%+ margin advantage or enables an entirely new market. Competitors have no viable alternative. |
| 4 | **Major** | The resource creates 20-50% margin advantage or significant pricing power. Competitors can partially substitute but at much higher cost. |
| 3 | **Significant** | The resource creates 10-20% margin advantage. Competitors have alternatives that partially close the gap. |
| 2 | **Modest** | The resource creates 5-10% margin advantage. Nice to have but not decisive. |
| 1 | **Marginal** | The resource provides <5% margin advantage. May not be sufficient to constitute Power. |

## 4. Durability and Risk Analysis

Every Cornered Resource faces specific risks to its continued value. Map and assess each risk.

### Risk Categories

| Risk | Description | Mitigation |
|------|------------|------------|
| **Expiration** | Patent, contract, or license reaching end of term | Pipeline development, extension strategies, diversification |
| **Departure** | Key people leaving (retirement, recruitment, burnout) | Succession planning, retention programs, team expansion |
| **Substitution** | Competitors developing alternative resources that achieve similar outcomes | Continuous innovation, broadening the resource advantage |
| **Regulatory Change** | Changes in law or regulation that eliminate or weaken the fiat barrier | Government relations, regulatory monitoring, geographic diversification |
| **Technology Disruption** | New technology making the resource less valuable | R&D investment, technology monitoring, adjacency expansion |
| **Market Shift** | Changes in customer needs or market structure that reduce the resource's relevance | Market sensing, customer research, portfolio diversification |

## 5. Power Scoring Matrix

Use this scoring framework to produce an overall assessment of Cornered Resource Power.

| Dimension | Weight | Score (1-10) | Weighted Score |
|-----------|--------|--------------|----------------|
| Five Screening Tests (Pass rate and strength) | 30% | | |
| Fiat Barrier Durability | 20% | | |
| Benefit Magnitude | 20% | | |
| Resource Exclusivity (how truly unique) | 15% | | |
| Risk-Adjusted Durability | 15% | | |
| **Total** | **100%** | | |

### Interpretation

| Total Weighted Score | Assessment |
|---------------------|------------|
| 8.0–10.0 | **Dominant Cornered Resource** — A powerful, well-protected competitive moat. The resource is genuinely exclusive, produces substantial differential returns, and is protected by a durable fiat barrier. |
| 6.0–7.9 | **Strong Cornered Resource** — Meaningful Power exists. The resource provides real competitive advantage with a defensible barrier, though some risks or limitations exist. |
| 4.0–5.9 | **Moderate Cornered Resource** — Some advantage from the resource, but it's not decisive. The barrier may have vulnerabilities, the benefit may be modest, or the screening tests produced mixed results. |
| 2.0–3.9 | **Weak Cornered Resource** — The resource provides marginal advantage. It may fail one or more screening tests, have a fragile barrier, or produce insufficient differential returns. |
| < 2.0 | **No Cornered Resource Power** — The suspected resource does not constitute Power. It may be valuable but doesn't meet the Cornered Resource criteria. Look for Power elsewhere. |

## 6. Deliverable Template

When producing a Cornered Resource assessment, structure it as follows:

### Cornered Resource Power Assessment: [Company/Product Name]

**Executive Summary** (2-3 sentences)
State whether Cornered Resource Power exists, how strong it is, and what resource it derives from.

**Business Context**
- Company/product being analyzed
- Primary competitors
- Lifecycle phase (Origination, Takeoff, or Stability)
- The suspected Cornered Resource and why it's being evaluated

**Five Screening Tests**
- Idiosyncratic: result and reasoning
- Non-Arbitraged: result and reasoning
- Transferable: result and reasoning
- Ongoing: result and reasoning
- Sufficient: result and reasoning
- Overall: Pass/Fail with confidence level

**Resource Classification**
- Type of Cornered Resource (IP, Physical, Human Capital, Regulatory, Data, Relationship)
- Specific description of the resource

**Fiat Barrier Assessment**
- Type of fiat (legal, personal, contractual, property, regulatory)
- Durability scoring
- Key vulnerability points

**Benefit Analysis**
- How the resource creates value (pricing power, cost advantage, superior product)
- Magnitude estimate
- Competitive impact

**Risk Analysis**
- Key risks to the resource's continued value
- Risk scoring
- Mitigation strategies

**Power Score**
- Completed scoring matrix
- Overall assessment rating

**Strategic Implications**
- What this means for the company's competitive strategy
- Recommendations for protecting and strengthening the Cornered Resource (if it exists)
- Recommendations for alternative strategy (if Cornered Resource is weak or absent)
- Succession/renewal planning (especially for human capital resources)
