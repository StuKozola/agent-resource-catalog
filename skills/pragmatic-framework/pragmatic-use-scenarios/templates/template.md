## Validation Checklist

Before sharing with stakeholders, confirm each scenario passes these checks:

- [ ] Exactly one persona
- [ ] Exactly one problem per scenario
- [ ] Solution-free (no features, UI elements, or "should/could/would")
- [ ] Grounded in NIHITO observation (not assumed)
- [ ] Emotional or business stakes are clear
- [ ] Linked to parent requirement
- [ ] Vivid enough that a developer would understand why this matters
