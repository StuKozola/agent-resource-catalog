# Provisional User Persona Template

> **Purpose:** A provisional persona is an early-stage hypothesis about a user type. It captures what the team believes about the user based on available knowledge, explicitly marking confidence levels so assumptions can be validated through research.
>
> **When to use:** Before or during early user research, when you need to align the team on initial assumptions and plan targeted research.
>
> **Instructions:** Fill in each section. For each attribute, mark confidence as:
> - **[DATA]** — Based on analytics, research findings, or documented evidence
> - **[STAKEHOLDER]** — Based on internal stakeholder experience with users
> - **[ASSUMPTION]** — A hypothesis that needs validation
