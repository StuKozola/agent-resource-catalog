# Refined User Persona

> **Purpose:** A refined persona is a research-validated archetype of a real user type. It serves as the authoritative reference for product decisions, design choices, and cross-functional alignment.
>
> **When to use:** After completing user research (8+ interviews per persona type), synthesizing findings, and validating behavioral clusters.
