## Learning path

| Phase | Content | Format | Time | Completion evidence |
|---|---|---|---|---|
| Pre-work | Primer, Value Framework, field tools | Self-paced | 1–2 h | Quiz / acknowledgement |
| Workshop | Concepts, personas, discovery, trap-setting, mantra, objections, live-deal application | Live | 1–2 days | Practice participation |
| Application | Use tools on real calls; manager call reviews | On the job | 2–4 weeks | 2+ reviewed calls |
| Certification | Scored role-plays and opportunity plan | Live | 45–60 min | Rubric score ≥ pass mark |
| Ongoing | Refreshers, framework updates | Mixed | Quarterly | Attendance |
